# class005 对数器 —— 验证的重要手段

> 本节是【入门】阶段的「自测工具课」。对数器 = **暴力解 + 随机样本产生器 + 对拍**，让你在没有在线测试（OJ）的情况下也能自我验证算法的正确性。
> 核心结论：**写一个一定对的暴力解，写一个想验证的最优解，随机生成成百上千组数据对拍；不一致就打印短样本 debug，一致就基本可信**。后面几乎每道题都能用它验证，尤其在贪心、找规律题上极有用。

---

## 一、为什么需要对数器（应用场景）

不要完全依赖线上 OJ 或别人给的测试数据，因为：

1. **找不到 OJ**：面试官现编的题、朋友遇到的题、网上新帖的题，经常没有在线测试。
2. **巨大错误样例难 debug**：OJ 只甩给你一个超长的错误用例，面对一大堆数无从下手。
3. **笔试只告诉通过率**：不通过时只告诉你「过了多少 / 没过多少」，不给你错误例子。
4. 结论：你得有一套**不依赖外部、自己就能验证**的方法，这就是对数器。

---

## 二、方法论

假设你要完成一个「有输入有输出」的功能（一道题），思路往往不止一种：

1. 写一个**暴力解**（方法 B）：容易想、大概率对，但时间复杂度不行、会超时。
2. 写一个**最优解**（方法 A）：你真正想实现、复杂度更好的解，但不确定对不对。
3. 写一个**随机样本产生器**：长度随机、值范围随机，且长度和值范围都能自己控制。
4. 让 A、B 跑**同一份**随机输入，比对结果（对拍）。
5. 结果不一致 → 打印这个出错的**短样本**，代入代码一步步排查；结果一致 → 多测成千上万组。
6. 小数据量验证通过后，**逐步放大**数据量（但别大到暴力解跑不完），确认依然一致。

> 为什么对拍一致就能认为都对？因为 A、B 是**两套独立思路**实现的，同时犯同一个错、还恰好结果一致的概率极低。

---

## 三、随机行为原理

Java 的 `Math.random()` → C++ 的 `rand()`（配合 `srand(time(0))` 播种）。

| 步骤 | Java | C++ |
|---|---|---|
| 得到 [0,1) 的小数 | `Math.random()` | （`rand()` 直接返回整数，见下） |
| 得到 [0,v) 的整数 | `(int)(Math.random() * v)` | `rand() % v` |
| 得到 [1,v] 的整数 | `(int)(Math.random() * v) + 1` | `rand() % v + 1` |

原理：`Math.random()` 等概率返回 [0,1) 上的 double；乘 `v` 放大到 [0,v)；`(int)` 强转截断小数得到 [0,v-1] 的等概率整数；`+1` 得到 [1,v] 的等概率整数。C++ 里 `rand() % v` 直接得到 [0,v-1] 的整数，`+1` 得 [1,v]。

## 四、实战：对数器验证三个排序

上节课的「选择排序 / 冒泡排序 / 插入排序」三个思路都能完成排序这一功能，正好拿来两两对拍——任何一个写错（比如选择排序的 `i` 笔误成从 1 开始）都会被立刻抓出来。

### 代码（完整）

```cpp
// 对数器 —— 验证的重要手段
// 对数器：当你写的算法没有在线测试(OJ)可测时，用「暴力解 + 随机样本 + 对拍」来自我验证。
//
// 方法论：
//   1. 写一个容易实现、能保证正确的暴力解（方法B）
//   2. 写你想验证的最优解（方法A）
//   3. 写随机样本产生器（长度、值范围都可控）
//   4. 让 A、B 跑同一份随机输入，比对结果（对拍）
//   5. 结果不一致就打印出错的短样本，代入 debug；一致则多测成千上万组
//   6. 小数据验证通过后，再逐步放大数据量
//
// 本节用「选择排序 / 冒泡排序 / 插入排序」三个思路完成排序这一功能，两两对拍，
// 任何一个写错（比如选择排序 i 笔误成从 1 开始）都能被立刻抓出来。

#include <bits/stdc++.h>
using namespace std;

const int MAXN = 100;   // 随机数组最大长度

int arr[MAXN];   // 原始随机数组
int arr1[MAXN];  // 拷贝1（选择排序）
int arr2[MAXN];  // 拷贝2（冒泡排序）
int arr3[MAXN];  // 拷贝3（插入排序）

// 选择排序
void selectionSort(int arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int minIndex = i;
        for (int j = i + 1; j < n; j++) {
            if (arr[j] < arr[minIndex]) minIndex = j;
        }
        swap(arr[i], arr[minIndex]);
    }
}

// 冒泡排序
void bubbleSort(int arr[], int n) {
    for (int end = n - 1; end > 0; end--) {
        for (int i = 0; i < end; i++) {
            if (arr[i] > arr[i + 1]) swap(arr[i], arr[i + 1]);
        }
    }
}

// 插入排序
void insertionSort(int arr[], int n) {
    for (int i = 1; i < n; i++) {
        for (int j = i - 1; j >= 0 && arr[j] > arr[j + 1]; j--) {
            swap(arr[j], arr[j + 1]);
        }
    }
}

// 随机数组生成器：把全局 arr 填成长度 n、每个值在 [1, v] 的随机数组
// Math.random() -> [0,1) 的小数；(int)(Math.random() * v) + 1 -> [1, v] 的整数
// C++ 用 rand() % v + 1 得到 [1, v] 的整数
void randomArray(int n, int v) {
    for (int i = 0; i < n; i++) {
        arr[i] = rand() % v + 1;
    }
}

// 拷贝数组：src -> dst（长度 n）
void copyArray(int src[], int dst[], int n) {
    for (int i = 0; i < n; i++) {
        dst[i] = src[i];
    }
}

// 判断两个数组（长度 n）每个位置是否都相等
bool sameArray(int a[], int b[], int n) {
    for (int i = 0; i < n; i++) {
        if (a[i] != b[i]) return false;
    }
    return true;
}

int main() {
    srand(time(0));
    int N = 100;            // 随机数组最大长度
    int V = 1000;           // 随机数组每个值在 [1, V]
    int testTimes = 50000;  // 测试次数

    cout << "测试开始" << endl;
    for (int i = 0; i < testTimes; i++) {
        int n = rand() % N;   // 长度在 [0, N-1]
        randomArray(n, V);    // 生成随机数组到 arr
        copyArray(arr, arr1, n);
        copyArray(arr, arr2, n);
        copyArray(arr, arr3, n);
        selectionSort(arr1, n);
        bubbleSort(arr2, n);
        insertionSort(arr3, n);
        if (!sameArray(arr1, arr2, n) || !sameArray(arr1, arr3, n)) {
            cout << "出错了!" << endl;
            cout << "原始数组: ";
            for (int j = 0; j < n; j++) cout << arr[j] << " ";
            cout << endl;
            cout << "选择排序: ";
            for (int j = 0; j < n; j++) cout << arr1[j] << " ";
            cout << endl;
            cout << "冒泡排序: ";
            for (int j = 0; j < n; j++) cout << arr2[j] << " ";
            cout << endl;
            cout << "插入排序: ";
            for (int j = 0; j < n; j++) cout << arr3[j] << " ";
            cout << endl;
            break;
        }
    }
    cout << "测试结束" << endl;
    return 0;
}
```

### 关键点说明

- **为什么拷贝三份、不让原始 `arr` 直接去排序**：一旦出错，你还能打印出「排序之前」的原始数组，拿到一个**短样本**去代入 debug。
- **出错时打印原始数组 + 三个排序结果**：一眼看出哪个排序出了错、错在哪。
- **`sameArray` 逐位比对**：某个位置不等就立刻 `return false`。

---

## 五、调试技巧（找错的标准流程）

1. 先把**数组长度调小**（如 5）、**值范围调小**（如 10）——有错的话小数据下一样会出错。
2. 出错后打印**排序前的原始数组**，得到一个「短样本」。
3. 拿这个短样本代入每个方法，用 **print 大法**或**断点**逐步看中间结果是否符合预期，定位错误位置。
4. 改对之后，小数据通过 → 逐步放大（长度 50/值 100 → 长度 500/值 1000 → …），每次都通过就基本可信了。
5. 注意别放大到**暴力解跑不完**的程度——最优解能跑大样例，但暴力解不能，所以只在中小数据量下对拍。

---

## 本节小结

1. **对数器 = 暴力解 + 随机样本 + 对拍**，是不依赖 OJ 的自我验证手段，门槛是要能写出「两套独立思路」的功能相同的方法。
2. **随机样本产生器**要同时可控「长度」和「值范围」；C++ 里 `rand() % v + 1` 得到 [1,v] 的整数。
3. **调试靠短样本**：缩小数据量 → 打印原始输入 → print 大法 / 断点逐步排查 → 改对后再放大。
4. 对数器在后续课程中会大量出现，是验证贪心、找规律、优化解正确性的利器。
