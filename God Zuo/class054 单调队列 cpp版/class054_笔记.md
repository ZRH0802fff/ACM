## 核心知识：单调队列

### 是什么 / 什么时候用

**单调队列**用来解决：滑动窗口移动过程中，**实时获取窗口内的最大值或最小值**。窗口右扩（r++）时元素入队，左缩（l++）时元素过期淘汰。

**识别特征：** 题目要求"滑动窗口最值"、"子数组 max-min ≤ limit"、"满足某条件的最短/最长子数组" → 考虑单调队列。

**时间复杂度：** O(n)，每个元素最多入队一次、出队一次，单次操作均摊 O(1)。可以结合动态规划做枚举优化（扩展课程）。

**实现：** 用全局数组 + `h`（队头）/ `t`（队尾）双指针，从队头到队尾维持单调性。需要用到**窗口内最小值**时维护单调**递增**队列，需要**最大值**时维护单调**递减**队列。

单调队列 = 滑动窗口 + 维持窗口内最值的结构。相比单调栈，多了**"过期淘汰"**（头部元素滑出窗口）。用全局数组 `q[MAXN]` + `h`（头）/ `t`（尾）指针实现。

### 核心原理——以求窗口最大值为例

队列从队头到队尾**严格递减**（存下标），队头永远当前窗口的最大值。

**进队（从队尾）：** 新元素要进队，把队尾 ≤ 它的全部弹出（这些元素"永远不可能成为最大"，被碾压了），然后自己入队。

**出队（从队头）：** 过期元素的下标如果 == 队头，队头出队。

### 单调栈 vs 单调队列

| | 单调栈 | 单调队列 |
|------|------|------|
| 淘汰方向 | 只从栈顶（单端） | 头过期 + 尾维护（双端） |
| 典型场景 | 找"最近且小/大" | 滑动窗口最值 |
| 指针 | 只用 `r`（栈顶） | `h`（头）+ `t`（尾） |

### 完整推演（以 nums=[4,3,5,4,3,3,6,7], k=3 为例）

求每个窗口的最大值。窗口大小 k=3，队列存下标，**严格递减**（值大的在前）。

| 步骤 | l | r | nums[r] | 操作 | 队列（下标） | 窗口 | 答案 |
|------|---|---|---------|------|-----------|------|------|
| 先建 k-1=2 的窗口 | — | 0 | 4 | 入队 | [0] | [4] | — |
|  | — | 1 | 3 | 3<4，入队 | [0,1] | [4,3] | — |
| 补齐并滑动 | 0 | 2 | 5 | 5>3弹1,5>4弹0，入队 | [2] | [4,3,**5**] | 5 |
|  | 1 | 3 | 4 | 0已过期→无操作；4<5入队 | [2,3] | [3,**5,4**] | 5 |
|  | 2 | 4 | 3 | 3<4入队 | [2,3,4] | [**5,4,3**] | 5 |
|  | 3 | 5 | 3 | 队列尾=3≤3弹4，入队 | [2,3,5] | [**4,3,3**] | 5 |
|  | 4 | 6 | 6 | 6>3弹5,6>3弹3,6>5弹2，入队 | [6] | [**3,3,6**] | 6 |
|  | 5 | 7 | 7 | 7>6弹6，入队 | [7] | [**3,6,7**] | 7 |

**详解第 5 步（r=4, nums[4]=3）：**
- 队列里是 `[2,3]`（下标），对应值 `[5,4]`（递减）
- 3 要进队，从队尾看：`nums[3]=4` ≥ 3？不对，`4 > 3` 不弹。所以 3 直接入队 → `[2,3,4]`
- 队头下标 2 对应值 5，还在窗口内（过期？l=2, 2≥2 不过期）
- 窗口 [l=2, r=4] = [5,4,3]，最大 = `nums[q[h]] = nums[2] = 5` ✅

**详解第 7 步（r=6, nums[6]=6）：**
- 队列 `[2,3,5]` 值 `[5,4,3]`。6 要进队：
  - 队尾 `nums[5]=3` ≤ 6 → **弹**（3 不可能做最大了，6 更大且更晚过期）
  - 队尾 `nums[3]=4` ≤ 6 → **弹**
  - 队尾 `nums[2]=5` ≤ 6 → **弹**
- 此时队头 `q[h]=2` 已过期（l=4, 2<4），h 早就该移了。弹完后队空，6 入队 → `[6]`
- 窗口 [4,3,3,6]，最大 = 6 ✅

## 01 滑动窗口最大值 — LeetCode 239

**题面：** 数组 nums 和窗口大小 k，返回每个窗口中的最大值。

**核心思路：** 单调递减队列（存下标）。先形成 k-1 的窗口，然后每次右边界 r 入队（弹出队尾 ≤ nums[r] 的），队头即当前窗口最大值。若队头 == 左边界 l（即将滑出），队头出队。

**坑点：** 先建 k-1 窗口再补 1 个开始滑动；过期检查用 `q[h] == l`。



**代码：**

```cpp
vector<int> maxSlidingWindow(vector<int>& nums, int k) {
    int n = nums.size(), m = n - k + 1; vector<int> ans(m);
    h = t = 0;
    for (int i = 0; i < k - 1; i++) {
        while (h < t && nums[q[t - 1]] <= nums[i]) t--;
        q[t++] = i;
    }
    for (int l = 0, r; l < m; l++) {
        r = l + k - 1;
        while (h < t && nums[q[t - 1]] <= nums[r]) t--;
        q[t++] = r;
        ans[l] = nums[q[h]];
        if (q[h] == l) h++;
    }
    return ans;
}
```

## 02 绝对差不超过限制的最长子数组 — LeetCode 1438

**题面：** 找到最长的连续子数组，使得子数组内任意两数差的绝对值 ≤ limit（即 max-min ≤ limit）。

**核心思路：** 同时维护两个单调队列：`maxQ`（递减，取窗口最大）和 `minQ`（递增，取窗口最小）。滑动窗口 `[l, r)`：在 `ok()` 检查通过的情况下尽量扩展 r，然后结算 l 开头的答案，再移动 l。

**坑点：** `ok()` 在加入前预判：`maxVal = max(number, 队头max)`，`minVal = min(number, 队头min)`，差值 ≤ limit 才加入。两个队列的过期检查各自独立。

**代码：**
```cpp
int longestSubarray(vector<int>& nums, int limit) {
    int n = nums.size(), ans = 0; maxH = maxT = minH = minT = 0;
    for (int l = 0, r = 0; l < n; l++) {
        while (r < n && ok(nums, limit, nums[r])) { push(nums, r); r++; }
        ans = max(ans, r - l);
        pop(l);
    }
    return ans;
}
```

## 03 花盆问题 — 洛谷 P2698

**题面：** n 个水滴 (x, y)，找一个最短的 x 区间使区间内 maxY - minY ≥ d。

**核心思路：** 按 x 排序。双单调队列维护窗口内 y 的最大/最小值。滑动窗口 `[l, r)`：不满足 `maxY-minY≥d` 就扩展 r，满足就结算 `ans = min(ans, x[r-1]-x[l])` 然后移 l。

**坑点：** 无满足区间返回 -1。

**代码：**
```cpp
sort(arr, arr + n, [](auto& a, auto& b) { return a.x < b.x; });
int ans = INT_MAX;
for (int l = 0, r = 0; l < n; l++) {
    while (!ok() && r < n) { push(r); r++; }
    if (ok()) ans = min(ans, arr[r - 1].x - arr[l].x);
    pop(l);
}
cout << (ans == INT_MAX ? -1 : ans) << "\n";
```
