在算法竞赛中，求组合数 $\binom{n}{m}$（即从 $n$ 个元素中选 $m$ 个的方案数）是非常基础且高频的考点。因为组合数的增长速度极快，竞赛中通常要求对一个大质数（如 $10^9+7$ 或 $998244353$）取模。

根据数据范围的不同，竞赛中最常用的组合数模板有以下三种。

## 1. 阶乘与乘法逆元法 (最常用，适用于 $N \le 10^6$)

这是竞赛中 **最标准、使用最广** 的模板。利用公式 $\binom{n}{m} = \frac{n!}{m!(n-m)!} \pmod P$。

除法取模需要用到**费马小定理**求乘法逆元。我们在预处理时，先求出所有阶乘，再用快速幂求出最大阶乘的逆元，最后倒推求出所有逆元。

- **时间复杂度**：预处理 $O(N)$，单次查询 $O(1)$。

C++

```
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 1e6 + 5;   // 根据题目修改最大范围
const int MOD = 1e9 + 7;    // 常见的模数，必须是质数

long long fac[MAXN]; // 阶乘数组
long long inv[MAXN]; // 阶乘逆元数组

// 快速幂计算 a^b % MOD
long long qpow(long long a, long long b) {
    long long res = 1;
    a %= MOD;
    while (b > 0) {
        if (b & 1) res = res * a % MOD;
        a = a * a % MOD;
        b >>= 1;
    }
    return res;
}

// 预处理阶乘和逆元
void init() {
    fac[0] = inv[0] = 1;
    // 1. 预处理阶乘
    for (int i = 1; i < MAXN; i++) {
        fac[i] = fac[i - 1] * i % MOD;
    }
    // 2. 费马小定理求最大阶乘的逆元
    inv[MAXN - 1] = qpow(fac[MAXN - 1], MOD - 2);
    // 3. 线性倒推求所有逆元：1/i! = (i+1)/(i+1)!
    for (int i = MAXN - 2; i >= 1; i--) {
        inv[i] = inv[i + 1] * (i + 1) % MOD;
    }
}

// 求组合数 C(n, m)
long long C(int n, int m) {
    if (m < 0 || m > n) return 0; // 不合法的情况
    // C(n, m) = n! * (m!)^-1 * ((n-m)!)^-1 % MOD
    return fac[n] * inv[m] % MOD * inv[n - m] % MOD;
}

int main() {
    init(); // 必须先调用初始化函数
    // cout << C(5, 2) << endl; // 输出 10
    return 0;
}
```

## 2. 递推法 / 杨辉三角 (适用于 $N \le 2000$)

利用组合数递推公式 $\binom{n}{m} = \binom{n-1}{m-1} + \binom{n-1}{m}$。不需要用到求逆元，适合模数不是质数，或者数据范围较小的情况。

- **时间复杂度**：预处理 $O(N^2)$，单次查询 $O(1)$。
- **空间复杂度**：$O(N^2)$，因此 $N$ 最大只能开到 $2000$ 到 $5000$ 左右。

C++

```
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 2005;
const int MOD = 1e9 + 7; // 如果题目不要求取模，去掉模数运算即可（但要注意爆 long long）
long long c[MAXN][MAXN];

void init() {
    for (int i = 0; i < MAXN; i++) {
        c[i][0] = 1; // C(i, 0) = 1
        for (int j = 1; j <= i; j++) {
            c[i][j] = (c[i - 1][j - 1] + c[i - 1][j]) % MOD;
        }
    }
}

long long C(int n, int m) {
    if (m < 0 || m > n) return 0;
    return c[n][m];
}
```

## 3. Lucas 定理 (适用于 $N, M$ 极大，但模数 $P$ 较小)

当 $N, M$ 达到 $10^{18}$ 级别，完全无法预处理，但模数 $P$ 比较小（通常 $P \le 10^5$ 且必须是质数）时使用。

核心公式：$\binom{n}{m} \equiv \binom{n \bmod P}{m \bmod P} \times \binom{n / P}{m / P} \pmod P$。

- **时间复杂度**：$O(P)$ 预处理（如果多次查询），单次查询 $O(P \log_P N)$。

C++

```
#include <bits/stdc++.h>
using namespace std;

long long MOD; // 注意：Lucas定理要求模数必须是较小的质数

// 快速幂
long long qpow(long long a, long long b) {
    long long res = 1;
    while (b) {
        if (b & 1) res = res * a % MOD;
        a = a * a % MOD;
        b >>= 1;
    }
    return res;
}

// 在模 P 较小的情况下，直接 O(P) 暴力算小组合数
long long C(long long n, long long m) {
    if (m < 0 || m > n) return 0;
    if (m > n - m) m = n - m;
    long long up = 1, down = 1;
    for (long long i = 1; i <= m; i++) {
        up = up * (n - i + 1) % MOD;
        down = down * i % MOD;
    }
    return up * qpow(down, MOD - 2) % MOD;
}

// 递归应用 Lucas 定理
long long Lucas(long long n, long long m) {
    if (m == 0) return 1;
    return C(n % MOD, m % MOD) * Lucas(n / MOD, m / MOD) % MOD;
}

int main() {
    MOD = 10007; // 假设较小质数模数
    // cout << Lucas(100000000000LL, 50000000000LL) << endl; 
    return 0;
}
```

在数论和算法竞赛中，最大公约数 (GCD)、最小公倍数 (LCM) 以及同余理论是极为重要的基础。特别是在处理大数取模时，稍有不慎就会溢出或得出负数。

以下是为你整理的实用模板和竞赛避坑指南：

## 1. GCD 与 LCM (最大公约数与最小公倍数)

虽然 C++17 在 `<numeric>` 库中直接提供了 `std::gcd` 和 `std::lcm`，但在很多环境下（或者为了拓展到扩展欧几里得）我们依然习惯手写。

**竞赛避坑警告**：求 LCM 时，**一定要先除后乘** `a / gcd(a,b) * b`，否则 `a * b` 极易在第一步就爆 `long long`。

C++

```
#include <iostream>
using namespace std;

// 欧几里得算法 (辗转相除法)
long long gcd(long long a, long long b) {
    return b == 0 ? a : gcd(b, a % b);
}

// 最小公倍数 (先除后乘防溢出)
long long lcm(long long a, long long b) {
    if (a == 0 || b == 0) return 0; 
    return a / gcd(a, b) * b;
}
```

## 2. 同余基本运算模板

在竞赛中，所有的加减乘法都要随时取模。 **最大天坑**：C++ 中的 `%` 运算符对于负数会返回负数（例如 `-2 % 5 = -2`），而在数学同余中我们需要正余数（应为 `3`）。因此减法取模必须特殊处理。

C++

```
long long MOD = 1e9 + 7;

// 加法同余
long long add(long long a, long long b) {
    return (a % MOD + b % MOD) % MOD;
}

// 乘法同余
long long mul(long long a, long long b) {
    return (a % MOD * (b % MOD)) % MOD;
}

// 减法同余 (必须加 MOD 再取模，防止 C++ 负数取模坑)
long long sub(long long a, long long b) {
    return ((a % MOD - b % MOD) + MOD) % MOD;
}
```
