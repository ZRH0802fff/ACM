## 核心知识：单调栈经典用法

### 是什么 / 什么时候用

**单调栈**用来解决：数组中每个位置，求**左右两侧离自己最近且比自己小（或大）的元素位置**。所有位置一次性求出，O(n)。

**识别特征：** 题目要求找"左边/右边第一个比自己小/大的数"、"最大矩形面积"、"子数组最小值之和"等 → 单调栈。

**时间复杂度：** O(n)，每个下标最多进栈一次、出栈一次，单次操作均摊 O(1)。可以和动态规划等技巧结合做枚举优化（扩展课程）。

**栈的方向规则：**
- 求"最近且**小**" → 栈底到栈顶**严格大压小**（大的在底，小的在上）
- 求"最近且**大**" → 栈底到栈顶**严格小压大**（小的在底，大的在上）

### 完整推演（以无重复数组 [2,5,6,7,3,4,1,8] 为例）

准备一个栈（存下标），从栈底到栈顶**严格大压小**。

**遍历阶段：**

| 步骤 | 当前 i | 值 | 操作 | 栈（底→顶） | 结算 |
|------|--------|-----|------|-----------|------|
| 1 | 0 | 2 | 入栈 | [0] | — |
| 2 | 1 | 5 | 5>2，入栈 | [0,1] | — |
| 3 | 2 | 6 | 6>5，入栈 | [0,1,2] | — |
| 4 | 3 | 7 | 7>6，入栈 | [0,1,2,3] | — |
| 5 | 4 | 3 | 3<7，弹 3 | [0,1,2] | 3: 左=2(六), 右=4(三) |
|   |   |   | 3<6，弹 2 | [0,1] | 2: 左=1(五), 右=4(三) |
|   |   |   | 3<5，弹 1 | [0] | 1: 左=0(二), 右=4(三) |
|   |   |   | 3>2，入栈 | [0,4] | — |
| 6 | 5 | 4 | 4>3，入栈 | [0,4,5] | — |
| 7 | 6 | 1 | 1<4，弹 5 | [0,4] | 5: 左=4(三), 右=6(一) |
|   |   |   | 1<3，弹 4 | [0] | 4: 左=0(二), 右=6(一) |
|   |   |   | 1<2，弹 0 | [] | 0: 左=-1, 右=6(一) |
|   |   |   | 栈空，入栈 | [6] | — |
| 8 | 7 | 8 | 8>1，入栈 | [6,7] | — |

**清算阶段：**

| 操作 | 结算 |
|------|------|
| 弹 7（八） | 左=6(一), 右=-1（不存在） |
| 弹 6（一） | 左=-1, 右=-1（不存在） |

**最终答案：**

| 下标 | 值 | 左边最近且小 | 右边最近且小 |
|------|-----|-----------|-----------|
| 0 | 2 | -1 | 6（值=1） |
| 1 | 5 | 0（值=2） | 4（值=3） |
| 2 | 6 | 1（值=5） | 4（值=3） |
| 3 | 7 | 2（值=6） | 4（值=3） |
| 4 | 3 | 0（值=2） | 6（值=1） |
| 5 | 4 | 4（值=3） | 6（值=1） |
| 6 | 1 | -1 | -1 |
| 7 | 8 | 6（值=1） | -1 |

**"大压小"规则总结：**
- 一个数要进栈 → 栈顶 ≥ 它的全弹出（结算），然后它压在小于它的数上面
- 求"最近且小"用**大压小**栈 → 求"最近且大"反过来用**小压大**栈

**为什么正确？** 若栈中 A 压在 B 上面 → B 在 A 左边且 B < A（否则 B 当初就不会被 A 压住）。AB 之间不可能有 < B 的数（有的话 B 早被弹了），也不可能有效值在 (B,A) 之间的数（有的话 A 就压在它上面而不是 B 上了），只可能有 > A 的数。所以 B 就是 A **左边**最近且小的数。同理，X 释放 A 时，如果 A 和 X 之间还有比 A 小的 Y，那 Y 早就释放 A 了轮不到 X → 所以 X 就是 A **右边**最近且小的数。

**复杂度：** O(n)——每个下标最多进栈一次、出栈一次。

### 有重复值的情况

相等时**也弹出**（严格大压小）。结算后，从右往左修正：如果 `arr[ansR[i]] == arr[i]`，则 `ansR[i] = ansR[ansR[i]]`（把相等值的答案传递下去）。左侧不需要修正——因为严格大压小保证了左边的正确性。

### 求"最近且大"怎么办？

反过来，栈里**小压大**即可。

## 01 单调栈模板

> 洛谷 P5788（本题求的是"右边第一个大于"，改一下比较方向即可）

**代码（求左右最近且小的模板）：**

```cpp
// 遍历阶段
r = 0;
for (int i = 0; i < n; i++) {
    while (r > 0 && arr[stk[r - 1]] >= arr[i]) {
        int cur = stk[--r];
        ansL[cur] = r > 0 ? stk[r - 1] : -1;
        ansR[cur] = i;
    }
    stk[r++] = i;
}
// 清算阶段
while (r > 0) {
    int cur = stk[--r];
    ansL[cur] = r > 0 ? stk[r - 1] : -1;
    ansR[cur] = -1;
}
// 修正阶段（相等值的右侧答案）
for (int i = n - 2; i >= 0; i--)
    if (ansR[i] != -1 && arr[ansR[i]] == arr[i])
        ansR[i] = ansR[ansR[i]];
```

## 02 每日温度 — LeetCode 739

**题面：** 给定温度数组，求每个位置到下一个更高温度的天数差。

**核心思路：** 求"右侧最近且严格大于" → 使用**小压大**的单调栈。栈里放的是下标，遍历时若栈顶温度 < 当前温度则弹出并结算 `ans[cur] = i - cur`。相等时直接入栈（让更大的数来统一释放这批相等的）。最终栈里剩余的自然为 0。

**坑点：** 相等时的处理——可以入栈，也可以弹出后再入。题目只求严格大于，相等不入结算。

**代码：**
```cpp
vector<int> dailyTemperatures(vector<int>& ts) {
    int n = ts.size(); vector<int> ans(n, 0); r = 0;
    for (int i = 0; i < n; i++) {
        while (r > 0 && ts[stk[r - 1]] < ts[i]) {
            int cur = stk[--r]; ans[cur] = i - cur;
        }
        stk[r++] = i;
    }
    return ans;
}
```

## 03 子数组的最小值之和 — LeetCode 907

**题面：** 数组 arr，求所有子数组的最小值之和，对 1e9+7 取模。

**核心思路：** 单调栈求每个元素作为最小值的**辐射范围**。遍历时弹出 cur，左侧到 `left`，右侧到 `i`（当前让 cur 弹出的位置）。以 cur 为最小值的子数组数 = `(cur - left) * (i - cur)`。贡献 = `子数组数 * arr[cur]`。遍历阶段 + 清算阶段分别累加。

**坑点：** 相同值时必须 `>=` 弹出，保证一侧严格小于、另一侧 ≤，避免重复计数。取模用 `long long` 防溢出。

**代码：**
```cpp
int sumSubarrayMins(vector<int>& arr) {
    int n = arr.size(); long long ans = 0; r = 0;
    for (int i = 0; i < n; i++) {
        while (r > 0 && arr[stk[r - 1]] >= arr[i]) {
            int cur = stk[--r], left = r > 0 ? stk[r - 1] : -1;
            ans = (ans + (long long)(cur - left) * (i - cur) * arr[cur]) % MOD;
        }
        stk[r++] = i;
    }
    while (r > 0) {
        int cur = stk[--r], left = r > 0 ? stk[r - 1] : -1;
        ans = (ans + (long long)(cur - left) * (n - cur) * arr[cur]) % MOD;
    }
    return (int)ans;
}
```

## 04 柱状图中最大的矩形 — LeetCode 84

**题面：** 直方图每条宽1，高为 height[i]，求最大矩形面积。

**核心思路：** 单调栈（大压小）。弹出 cur 时，左边最近更矮的 = `left`，右边最近更矮的 = `i`。cur 柱子的高度能**完整覆盖**的宽度 = `i - left - 1`。面积 = `height[cur] * (i - left - 1)`。遍历 + 清算取最大面积。

**坑点：** 清算阶段右边界为 n，宽度 = `n - left - 1`。面积超过 INT_MAX 的场景不存在（高度最大 10000）。

**代码：**
```cpp
int largestRectangleArea(vector<int>& height) {
    int n = height.size(), ans = 0; r = 0;
    for (int i = 0; i < n; i++) {
        while (r > 0 && height[stk[r - 1]] >= height[i]) {
            int cur = stk[--r], left = r > 0 ? stk[r - 1] : -1;
            ans = max(ans, height[cur] * (i - left - 1));
        }
        stk[r++] = i;
    }
    while (r > 0) {
        int cur = stk[--r], left = r > 0 ? stk[r - 1] : -1;
        ans = max(ans, height[cur] * (n - left - 1));
    }
    return ans;
}
```

## 05 最大矩形 — LeetCode 85

**题面：** 01 矩阵，求全由 1 组成的最大矩形面积。

**核心思路：** 逐行压缩成直方图。每行：`matrix[i][j]=='0'` → `height[j]=0`，否则 `height[j]+=1`。然后在每行的直方图上跑**柱状图最大矩形**（题目4）。取所有行的最大值。

**坑点：** height 数组全局复用，逐行修改后直接在当前行跑单调栈，不需要复制。

**代码：**
```cpp
int maximalRectangle(vector<vector<char>>& matrix) {
    int n = matrix.size(), m = matrix[0].size(), ans = 0;
    memset(height, 0, sizeof(height));
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++)
            height[j] = matrix[i][j] == '0' ? 0 : height[j] + 1;
        r = 0;
        for (int j = 0; j < m; j++) {
            while (r > 0 && height[stk[r - 1]] >= height[j]) {
                int cur = stk[--r], left = r > 0 ? stk[r - 1] : -1;
                ans = max(ans, height[cur] * (j - left - 1));
            }
            stk[r++] = j;
        }
        while (r > 0) {
            int cur = stk[--r], left = r > 0 ? stk[r - 1] : -1;
            ans = max(ans, height[cur] * (m - left - 1));
        }
    }
    return ans;
}
```
