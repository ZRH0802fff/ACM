## 公共背景：PPT 推导 + 使用条件

### 0. 定义

- 欧拉路径（半欧拉图）：一笔画，每条边恰好经过一次，起点 ≠ 终点
- 欧拉回路（欧拉图）：起点 = 终点的欧拉路径

---

### 1. 使用条件（什么时候存在欧拉回路 / 欧拉路径）

这是三道题共用的**判定依据**，PPT 讲得最细的部分。

#### 1.1 有向图存在欧拉回路的条件

> 注意两个前提：**忽略入度出度都为 0 的点** + **剩余图强连通**。

1. 忽略入度和出度都为 0 的点后，剩下每个点满足 `入度 == 出度`
2. 剩余图是**强连通**的（任意两点可以互相到达）

**为什么两个条件缺一不可：**

- 条件 1 是"局部"保证：每个点进去几条边就能出来几条边，走进去一定走得出来，所以路径能"走到底再回来"。
- 条件 2 是"整体"保证：若图不连通（有多个强连通分量），从一个分量出发永远走不到另一个分量，边一定走不完。所以必须强连通。
- "忽略度为 0 的点"是因为孤立点没有边，不参与路径，不影响判定。

#### 1.2 有向图存在欧拉路径的条件

1. 忽略入度和出度都为 0 的点后，除了起点和终点外，剩下每个点满足 `入度 == 出度`
2. 起点 `出度 == 入度 + 1`，终点 `入度 == 出度 + 1`，**有且仅有**一个起点和一个终点
3. 判断技巧：**终点向起点再连一条有向边**，接下来判定是否有欧拉回路即可

**推导第 3 条为什么成立：**

欧拉路径和欧拉回路的差别，只在"起点、终点各差 1 条边"。若给终点补一条到起点的边，那么：

- 起点：原本出度多 1，加上终点连来的这条入边 → `入度 == 出度`
- 终点：原本入度多 1，加上连出去这条出边 → `入度 == 出度`

于是所有点都平衡了，问题就**归约成"判定欧拉回路"**。这解释了为什么第 1、2 条条件里，只有起点终点允许偏差恰好 1。

#### 1.3 无向图存在欧拉路径 / 回路的条件

1. 忽略度为 0 的点后，剩余的图**全连通**
2. 统计度为奇数的点的个数，记为 `odd`
3. `odd == 0` → 存在欧拉回路
4. `odd == 2` → 存在欧拉路径
5. 否则（`odd` 为其他值）不存在欧拉回路或欧拉路径
6. 证明过程与有向图的证明过程相似

**为什么看奇度点：**

无向图里，一条欧拉路径每"经过"一个中间点就消耗 2 个度（一进一出），所以中间点必须是偶度；只有起点和终点可以各"欠"1 个度（奇度）。因此奇度点只可能是 0 个（回路，起终点重合）或 2 个（路径的起终点）。

---

### 2. 构造性的证明（有向图欧拉回路为什么能构造出来）

> 这就是 Hierholzer 算法正确性的来源，PPT 的"构造性的证明"，共 5 步。

1. 从任意点 s 出发，如果遇到出边就选一条继续走，最终走到无法再走，**一定会回到 s**，认为生成了"主线"。
2. 如果有剩余的边没有走到，那么该边**必然可被主线上的某点 x 找到**，因为图是强连通的。
3. 从点 x 出发，继续仿照步骤 1，继续走没有走过的边，最终一定回到 x，认为生成了"支线"。
4. 把 x 走出的支线，**插入到主线里**，可以拼成一个欧拉回路。
5. 主线不停插入支线，最终可以得到整个欧拉回路。这就是 Hierholzer 算法。

---

### 3. Hierholzer 算法（当前弧优化 + 回溯记录）

```cpp
void euler(int u) {
    for (int e = cur[u]; e > 0; e = cur[u]) {
        cur[u] = nxt[e];   // 当前弧优化：已走过的边 cur 后移，每条边只走一次
        euler(to[e]);       // 递归走掉这条边
    }
    path[++cntp] = u;      // 回溯时才记录节点
}
```

**课上重点图解：递归如何完成"插入支线"**

构造性证明里的"把支线插入主线"不是真的去改数组，而是**递归回溯天然做到的**。

拿一个例子图解：有向图，边 `1→2、2→3、3→1`（主线环）和 `1→4、4→1`（挂在点 1 的支线环）。从 1 出发：

| 调用 | 动作 | 递归后 path |
|---|---|---|
| euler(1) | 走 1→2 | — |
| euler(2) | 走 2→3 | — |
| euler(3) | 走 3→1 | — |
| euler(1)② | 走 1→4 | — |
| euler(4) | 走 4→1 | — |
| euler(1)③ | 无出边，回溯 | [1] |
| euler(4) | 无出边，回溯 | [1,4] |
| euler(1)② | 无出边，回溯 | [1,4,1] |
| euler(3) | 无出边，回溯 | [1,4,1,3] |
| euler(2) | 无出边，回溯 | [1,4,1,3,2] |
| euler(1) | 无出边，回溯 | [1,4,1,3,2,1] |

倒序输出：`1 2 3 1 4 1`，即 `1→2→3→1→4→1`，支线 `1→4→1` 被插进了主线 `1→2→3→1` 的点 1 处。

**要点：**
- 节点是**回溯时**才压入 path，所以支线会在回溯时"展开"在主线中间。
- 最终 `path` 是逆序的，`path[cntp] ... path[1]` 才是真正的欧拉路径 / 回路。

---

### 4. 判定与生成的完整流程

1. 根据条件（上面的使用条件）**找到起点**
2. 从起点开始，通过 Hierholzer 算法**生成路径**
3. **连通性的判定可以借助 Hierholzer**：看看能否走完所有边（`cntp == m + 1`），无需并查集等更复杂的手段

### 5. 一些提醒（PPT 原文要点）

1. 判定分两步：能否找到起点 + 生成的路径能否包含所有边。
2. 最终生成的路径数组，**倒序输出**才是真正的欧拉路径 / 欧拉回路。
3. 对于无向图，根据**无向边的序号是否已使用**来执行 Hierholzer 算法（即 `vis[eid]` 去重）。
4. 要求最小字典序等其他要求时，**每个点的边集进行排序**即可。
5. 时间复杂度 `O(n + m)`，如果有排序过程，复杂度再乘 `O(log m)`。

## 题目1：有向图的欧拉路径

### 题面
n 个点、m 条有向边，存在欧拉路径则输出**字典序最小**的结果，否则打印 `No`。

- 1 ≤ n ≤ 10^5，1 ≤ m ≤ 2×10^5
- Luogu P7771

### 核心思路
有向图欧拉路径判定 + Hierholzer 构造，字典序最小靠**建边顺序**解决。

### 关键过程

**1. 字典序最小 → 排序后逆序插边**

链式前向星的 head 是头插，若按 `(u, v)` 升序正向插入，DFS 时会先走**后插入**的边（即 v 大的边），不符合字典序。所以：

```cpp
sort(edgeArr + 1, edgeArr + m + 1, EdgeCmp);   // 按 (u, v) 升序
for (int l = 1, r = 1; l <= m; l = ++r) {
    while (r + 1 <= m && edgeArr[l].u == edgeArr[r + 1].u) r++;
    for (int i = r; i >= l; i--) {             // 同一组 u 逆序插入
        addEdge(edgeArr[i].u, edgeArr[i].v);   // → head 链变成 v 升序
    }
}
```

逆序插入后，head[u] 链表的顺序就是 v 升序，DFS 先走 v 小的边，输出即字典序最小。

**2. 找起点 `directedStart()`（对应使用条件 1.2）**

```cpp
int start = -1, end = -1;
for (int i = 1; i <= n; i++) {
    int v = outDeg[i] - inDeg[i];
    if (v < -1 || v > 1 || (v == 1 && start != -1) || (v == -1 && end != -1))
        return -1;                 // 偏差越界，或起点/终点不唯一
    if (v == 1) start = i;         // 出度 - 入度 = 1 → 起点
    if (v == -1) end = i;          // 入度 - 出度 = 1 → 终点
}
if ((start == -1) ^ (end == -1)) return -1;   // 起点终点必须同时有或同时无
if (start != -1) return start;
for (int i = 1; i <= n; i++)       // 全平衡 → 欧拉回路，任取出度>0的点
    if (outDeg[i] > 0) return i;
return -1;
```

**3. 判定两步 + 倒序输出**

```cpp
int start = directedStart();
if (start == -1) { cout << "No\n"; }
else {
    euler(start);
    if (cntp != m + 1) { cout << "No\n"; }   // 边没走完 → 不连通/无解
    else {
        for (int i = cntp; i >= 1; i--) cout << path[i] << " ";  // 倒序！
        cout << "\n";
    }
}
```

### 坑点
- `cntp != m + 1` 意味着有边没走到（图不满足条件），必须判，不能只判起点。
- 输出是**倒序**。

## 题目2：无向图的欧拉路径

### 题面
给定 m 条无向边（节点编号 [1, 500]，以边为准），输出**字典序最小**的欧拉路径，不存在打印 `No`。

- 1 ≤ m ≤ 1024
- Luogu P2731

### 核心思路
无向图欧拉路径判定 + Hierholzer；无向边拆成两条有向边，用**边 id 去重**防止正反向重复走。

### 关键过程

**1. 无向边拆两条，共享同一个 id**

```cpp
struct Edge { int u, v, id; };
// 读入每条无向边 (u, v, i)，拆成两条：
edgeArr[++k] = { u, v, i };
edgeArr[++k] = { v, u, i };
```

**2. 找起点 `undirectedStart()`：数奇度点（对应使用条件 1.3）**

```cpp
int odd = 0;
for (int i = 1; i <= n; i++) if ((deg[i] & 1) == 1) odd++;
if (odd != 0 && odd != 2) return -1;        // 奇度点不是 0 或 2 → 无解
for (int i = 1; i <= n; i++) {
    if (odd == 0 && deg[i] > 0) return i;              // 回路：取度>0 的最小点
    if (odd == 2 && (deg[i] & 1) == 1) return i;       // 路径：取奇度点（字典序取小）
}
return -1;
```

**3. Hierholzer 用 `vis[eid]` 去重（对应提醒第 3 条）**

无向边拆成了两条有向边，一条无向边走过后，正反两个方向都不能再走，所以用边的 id 标记：

```cpp
void euler(int u) {
    for (int e = cur[u]; e > 0; e = cur[u]) {
        cur[u] = nxt[e];
        if (!vis[eid[e]]) {      // 这条无向边还没走过
            vis[eid[e]] = true;
            euler(to[e]);
        }
    }
    path[++cntp] = u;
}
```

**4. 判定 + 输出** 与题目 1 完全一致：`start == -1` 或 `cntp != m + 1` 打印 `No`，否则 `path` 倒序每行输出一个点。

### 坑点
- 无向图必须靠 `vis[eid]` 去重，否则一条边会被正反向各走一次。
- 字典序同样靠"排序后逆序插边"实现，与题目 1 相同。

## 题目4：词链

### 题面
n 个由小写字母组成的单词，串成词链，要求前一个单词的**结尾字符 == 后一个单词的开头字符**。每个单词恰好用一次（同一单词出现 k 次就用 k 次）。输出**字典序最小**的词链（`.` 的字典序 < 小写字母），不存在输出 `***`。

- 1 ≤ n ≤ 1000
- Luogu P1127

### 核心思路
**单词当作边**：起点 = 首字母，终点 = 尾字母，边权 = 单词字符串本身。26 个字母是节点（a~z → 1~26），有向图跑欧拉路径，收集的是**边**（单词）而不是节点。

### 关键过程

**1. 建图：单词 → 边，字母 → 点**

```cpp
int startNode(const string &s) { return s[0] - 'a' + 1; }              // 首字母
int endNode(const string &s)   { return s.back() - 'a' + 1; }          // 尾字母
// addEdge(u, v, weight) 的 weight 就是单词本身
```

**2. 字典序最小：按 (起点, 单词) 排序**

`. ` 的 ASCII(46) < `a`(97)，所以直接用 `string` 的 `<` 比较单词，天然满足"`.` 最小 + 字典序最小"，再逆序插边：

```cpp
bool EdgeCmp(int i, int j) {
    if (a[i] != a[j]) return a[i] < a[j];
    return str[i] < str[j];        // '.' < 'a' 由 string 比较天然保证
}
```

**3. Hierholzer 收集的是边权（单词）**

```cpp
void euler(int u, string w) {
    for (int e = cur[u]; e > 0; e = cur[u]) {
        cur[u] = nxt[e];
        euler(to[e], weight[e]);   // 带着当前边权（单词）递归
    }
    path[++cntp] = w;              // 回溯压入单词
}
// 初始调用 euler(start, "")，path[1] 是空串哨兵
```

**4. 输出：path 倒序，用 `.` 连接（跳过空串哨兵）**

```cpp
if (start == -1) { cout << "***\n"; }
else {
    euler(start, "");
    if (cntp != m + 1) { cout << "***\n"; }   // 单词没连完 → 无解
    else {
        cout << path[cntp - 1];                 // path[cntp] 是空串哨兵，跳过
        for (int i = cntp - 2; i >= 1; i--) cout << "." << path[i];
        cout << "\n";
    }
}
```

### 坑点
- 与题目 1、2 不同，这里 **path 收集的是边（单词），不是节点**，输出时无需再查节点编号，直接倒序拼单词即可。
- 初始 `euler(start, "")` 会往 path 塞一个空串，输出时要跳过（从 `cntp-1` 开始，而不是 `cntp`）。
- 起点判定与有向图欧拉路径完全一致（26 个字母上的有向图）。

## 三题小结

| | 图类型 | 节点 | 边 | 字典序关键 | 特殊点 |
|---|---|---|---|---|---|
| 题1 | 有向 | 点编号 | 有向边 | (u,v) 排序逆插 | 标准有向欧拉路径 |
| 题2 | 无向 | 点编号 | 无向边拆两条 | (u,v) 排序逆插 | `vis[eid]` 去重 |
| 题4 | 有向 | 26 个字母 | 单词 | (起点,单词) 排序逆插 | path 收集边，`.` 最小 |

共性：**判定两步（找起点 + 边是否走完 `cntp == m+1`）**、**Hierholzer 回溯记录 + 倒序输出**、**排序后逆序插边保证字典序**。
